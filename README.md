# Bon & Malin — Fast-food.github.io

Un mini-site statique en français pour découvrir des idées de repas rapides à prix doux, dans une ambiance vert sauge, orange pâle et blanc.

## Lancer le site

Ouvre `index.html` dans un navigateur. Les photos sont chargées depuis Unsplash et les polices depuis Google Fonts ; une connexion Internet est nécessaire pour les afficher.

## Contenu

- Cartes de repas avec prix indicatifs, repère Nutri-Score estimatif et allergènes susceptibles d’être présents.
- Filtres par option végétarienne et budget, ainsi qu’une recherche.
- Mise en page responsive pour mobile et ordinateur.
- Mentions de transparence : les scores ne sont pas officiels pour les plats de restaurant, les tarifs varient et les allergènes doivent être vérifiés auprès de l’enseigne.

## Publication avec GitHub Pages

Dans GitHub, ouvre **Settings → Pages**, choisis **Deploy from a branch**, puis sélectionne `main` et `/ (root)`. Enregistre : le site sera publié à l’adresse `https://eliana1104.github.io/Fast-food.github.io/` après le déploiement. La publication peut prendre quelques minutes.

Les prix, compositions, scores indicatifs et allergènes sont des exemples pédagogiques, non des informations nutritionnelles ou tarifaires garanties. En cas d’allergie, contacte directement le restaurant.
